# 探索型搜索方法

目标：从本次图片样本归纳完整实物款式，尽量召回各相关方向的货源，供选款与供应研究。

1. 用户原词或核心品类宽词首搜，保存完整商品与来源。平台同义词可用于召回，记录派生依据。
2. 归并后在主线第 6 步加载 [款式原型方法](style-prototypes.md)。以差异样本建立原型，逐商品持续比较；批次是图片读取单元，原型定义在批次间共享。
3. 新发现触发原型修订及旧样本回查。审阅稿展示全部图组与边界组；通过审阅后形成选款比较。
4. 视觉判断后读取标题和 SKU，补充平台常用叫法、记录图文冲突；用确认原型的真实代表图和有证据的平台词补搜。
5. 每轮登记新增唯一商品、新增相关商品、新商家与重复比例，并记录新款式或边界变化。新增图片进入比较循环，原有图片复用可追溯观察并复核归属。
6. 按任务预算、边际新增、已尝试方向和服务边界停止；代表款数量不定义完成。当前 CLI 未验证真正分页，前 N 条不能证明全平台供给。

返回主线第 4/5 步继续召回或归并；停止后进入第 9 步整理结果。未完成审阅或回查时交付 partial。
