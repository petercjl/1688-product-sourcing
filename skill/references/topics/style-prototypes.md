# 完整实物款式原型与持续比较

来源：W/U，用户确认的《从商品图片归纳产品款式》（2026-09-30），本页将通用判断方法编译为找货节点规则。运行时只依赖本页和当前图像证据。

## 输入、问题与返回

输入：可追溯的商品 ID、原图及图片指纹。问题：样本中有哪些值得分别选款、采购或开发的完整实物方案？输出：原型目录、逐商品归属、变更回查记录、图片组审阅。完成后回主线第 7 步；具体字段在整理目录时读 output-contract.md。

## 差异样本建立原型

从外观差异较大的样本提出候选原型；名称、数量和边界随本批图片归纳。每个原型保存完整实物定义、真实代表图、纳入规则、排除条件与易混淆近款、独立选款意义、证据和未知项。标签是辅助证据；原型描述能让人想象并寻找一种真实商品方案。原型不套用特定品类的固定类别表。

## 逐商品持续比较

把新图与代表图、边界样本放在一起观察。相同设计的颜色、尺寸、普通配件变化记录为变体。关键结构、使用方式或整体设计方案不同，比较其他原型或提出新原型。判断粒度的问题是：是否需要分别比较供应商、功能验证、价格与竞品？需要则分开；常规配置留在同款下。真实稀有款保留并写低样本状态。

一图展示多个可辨认的不同款式时，逐个记录可见实物与多个 style_id。配件为主、主体不清或无法识别时保留待定原因与未知项。图片不能证明材质、性能、精确尺寸、人群或利润；商家声明与可见事实分开。

## 增量与回查

每轮保存新目录版本。新增、合并、拆分或调整边界均记录原因、受影响旧商品、实际回查商品；初次提出原型可记录空的旧商品范围。只重做新增或图片变化的观察，保留旧图指纹和证据；原型变化后重新判断受影响归属。已完成任务必须清空回查欠项。批次可逐图或并发执行，每批最多 10 张，并保持逐商品映射。

## 图片组审阅

按款式展示代表图、全部成员与边界组，链接回原图和商品记录。检查组内是否像同一种货、组间差异是否有实物证据、多款同图是否正确、早期样本是否已回查。默认提交用户审阅；经明确授权可由 Agent 自审，记录实际审阅者、版本、覆盖商品与结论。新版本使旧批准失效。争议保留待核实，不强行分组。

审阅通过后才接入商业机会判断；审阅稿可展示原始价格以供核对，但不把未经审阅分类写成市场结论。每组显示归属数，总数按商品 ID 去重，组数相加可以超过唯一商品总数。
